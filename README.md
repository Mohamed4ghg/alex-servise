# Alex Service — نظام إدارة الشحن والتوصيل

هذا هو الأساس البرمجي (Phase 1 من خطة التنفيذ) لمنصة **Alex Service** لإدارة الشحن، مبني بـ Next.js 16 و TypeScript و Tailwind CSS v4، بهوية بصرية كاملة (كحلي/أبيض/أحمر) وواجهة RTL بالكامل.

## التشغيل على جهازك (VS Code)

يتطلب [Node.js](https://nodejs.org) إصدار 20 أو أحدث.

```bash
# 1) فك الضغط وافتح المجلد في VS Code
cd alex-service

# 2) تثبيت الحزم
npm install

# 3) تشغيل السيرفر المحلي
npm run dev
```

بعدها افتح المتصفح على: **http://localhost:3000**

للتحقق من جاهزية النظام للنشر (Production Build):

```bash
npm run build
npm run start
```

> ملاحظة: أول مرة تشغّل فيها `npm run build` أو `npm run dev`، لازم يكون عندك اتصال إنترنت طبيعي علشان يجيب خطوط Google Fonts (Cairo و Tajawal). لو الجهاز خلف بروكسي، راجع تعليمات `next/font/google` في التوثيق الرسمي.

## الحالة الحالية — ما تم إنجازه (Phase 1 من خطتك)

- ✅ الهوية البصرية الكاملة (Design Tokens في `globals.css`) — كحلي / أبيض / أحمر / رمادي
- ✅ Landing Page كاملة (Hero, إحصائيات متحركة, المميزات, كيف نعمل, أسئلة شائعة, Footer)
- ✅ بوابة تتبع الشحنات العامة
- ✅ صفحة تسجيل الدخول (مصادقة تجريبية — تحتاج ربط حقيقي)
- ✅ لوحة التحكم: KPIs، Charts (Recharts)، تنبيهات، ملخص المندوبين، آخر الشحنات
- ✅ إدارة الشحنات: جدول + فلاتر بحث كاملة
- ✅ معالج إضافة شحنة (5 خطوات) بتوليد رقم تتبع تلقائي
- ✅ صفحة تفاصيل الشحنة + السجل الزمني الكامل
- ✅ إدارة المندوبين (قائمة + لوحة تفاصيل)
- 🚧 بقية الأقسام (العملاء، التحصيلات، المرتجعات، التقارير، الصلاحيات، سجل الأنشطة، الإعدادات، التتبع المباشر GPS) موجودة كصفحات Placeholder موسومة بمرحلة التنفيذ الخاصة بها، جاهزة للبناء عليها.

## البيانات

كل البيانات حاليًا **Mock Data** في `src/lib/mock-data.ts` — مصممة لتُستبدل مباشرة بطلبات API حقيقية (مثلاً Supabase) بدون تغيير شكل الواجهات، لأن كل الـ Components تستهلك من `src/lib/types.ts`.

## الخطوة التالية المقترحة

1. إعداد مشروع Supabase (PostgreSQL + Auth + Realtime + Storage).
2. تصميم الجداول حسب `src/lib/types.ts` كنقطة بداية.
3. استبدال دوال `mock-data.ts` بطلبات حقيقية (`supabase.from(...)`).
4. تفعيل Authentication حقيقي في صفحة `/login`.
5. بعد استقرار الويب، ننتقل لتطبيق المندوب (PWA / React Native) والتطبيق على أندرويد و iOS.
